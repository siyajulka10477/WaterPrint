# WaterPrint 💧

WaterPrint is a simple web application that helps users calculate and understand their daily water footprint. It measures both **direct water usage** (like showers and washing) and **virtual water usage** (the hidden water used to produce food and products).

---

## Features

- **Food Footprint:** Calculate virtual water from daily food consumption (rice, wheat, milk, tea, coffee, vegetables, meat, etc.).
- **Product Footprint:** Estimate hidden water in clothes and products (T-shirts, jeans, shoes, etc.).
- **Direct Water Usage:** Enter daily water usage from showers, laundry cycles, and household taps.
- **Results Dashboard:** Visual breakdown of your footprint with charts and summary cards.
- **Water Concepts & Methodology:** Learn about virtual water, direct water, and where the estimates come from.

---

## Tech Stack

- React + Vite
- Tailwind CSS
- Recharts
- Lucide React

---

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/siyajulka10477/WaterPrint.git
   cd WaterPrint
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173` in your browser.
